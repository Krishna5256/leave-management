\# Leave Management System



A simple Leave Management Module developed as part of an interview assessment.



\## Features



\- Manage 10 employees

\- Employee leave application

\- From Date and To Date

\- Annual, Sick and Casual leave types

\- Leave reason

\- Automatic leave day calculation

\- Pending, Approved and Rejected statuses

\- Admin/Manager approval and rejection

\- Employee leave history

\- Leave balance update after approval

\- Separate Employee and Admin/Manager portals



\## Technology Stack



\### Frontend

\- Next.js

\- React

\- TypeScript

\- Tailwind CSS



\### Backend

\- Node.js

\- Express.js

\- Prisma ORM



\### Database

\- SQLite
